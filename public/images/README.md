# Dish images

Drop dish photos here using the **exact filenames** below (any of `.jpg`,
`.png`, `.webp` works). Once a file exists, point its menu item at it in
`data/menu.ts`, e.g. `image: "/images/masala-dosey.jpg"`.

Until a real photo is added, the dish falls back to a branded gradient + emoji
(see `components/SmartImage.tsx`), so the UI never looks broken.

Tips: roughly square or 4:3 crops work best for cards; the hero plate is
circular, so keep the dosa centred in `masala-dosey`.
